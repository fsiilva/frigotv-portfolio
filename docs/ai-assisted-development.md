# Desenvolvimento assistido por IA

## Contexto

ChatGPT e OpenAI Codex foram utilizados como ferramentas de engenharia durante o desenvolvimento do projeto.

O uso de IA não substituiu o processo de levantamento de requisitos ou validação da solução.

## Fluxo utilizado

```text
Problema
  ↓
Levantamento de requisitos
  ↓
Definição das regras de negócio
  ↓
Planejamento
  ↓
Implementação assistida por IA
  ↓
Revisão
  ↓
Testes
  ↓
Correções
  ↓
Git / GitHub
  ↓
Deploy
  ↓
Validação em produção
```

## Aplicações da IA

- discussão e refinamento da arquitetura;
- geração de componentes;
- implementação de APIs;
- refatoração;
- investigação de erros;
- construção de consultas;
- revisão de código;
- criação de documentação;
- auxílio na criação de testes;
- análise de regras de negócio.

## Responsabilidades humanas no projeto

- identificação do problema;
- definição do produto;
- contato com usuários;
- levantamento de requisitos;
- regras de negócio;
- validação das respostas da IA;
- testes funcionais;
- decisões de infraestrutura;
- segurança operacional;
- versionamento;
- deploy;
- acompanhamento em produção.

## IA dentro do produto

O projeto também possui uma funcionalidade independente de IA generativa integrada à aplicação para geração de conteúdo promocional.

Isso deve ser diferenciado do desenvolvimento assistido por IA:

1. **IA como ferramenta de engenharia:** ChatGPT/Codex durante o desenvolvimento.
2. **IA como funcionalidade do produto:** integração com um modelo generativo para criação de conteúdo.
