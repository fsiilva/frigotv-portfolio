# Publicação segura

Antes de publicar qualquer código derivado do projeto real, valide:

- [ ] Nenhum arquivo `.env` está versionado
- [ ] Nenhuma chave de API aparece no histórico
- [ ] Nenhuma senha ou token está no código
- [ ] URLs corporativas foram removidas
- [ ] Dados de clientes foram removidos
- [ ] Dumps de banco não foram adicionados
- [ ] Logs não contêm dados sensíveis
- [ ] Screenshots não exibem e-mails, telefones ou credenciais
- [ ] O código publicado pode ser mostrado fora da empresa
- [ ] O README deixa claro que esta é uma versão de portfólio
